# 🥗 Contador de Calorías

**Contador_Calorías** es una aplicación que permite llevar un registro de los alimentos consumidos durante el día y calcular la cantidad total de calorías ingeridas. Está pensada para usuarios que desean controlar su alimentación, mejorar sus hábitos nutricionales o llevar un seguimiento diario de su ingesta calórica.

## ✅ Características

- Añadir alimentos con su valor calórico.
- Registrar comidas por hora o categoría (desayuno, almuerzo, cena, snacks).
- Calcular el total de calorías consumidas en el día.
- Ver historial de consumo o resumen diario.
- Posibilidad de establecer un objetivo calórico diario.

## 📦 Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu_usuario/Contador_Calorias.git
   ```
2. Entra al directorio del proyecto:
   ```bash
   cd Contador_Calorias
   ```
3. Ejecuta el programa:
   ```bash
   python contador_calorias.py
   ```

## 📝 Uso

1. Inicia el programa.
2. Ingresa los alimentos que has consumido y sus calorías.
3. Consulta el total de calorías diarias y compara con tu objetivo.
4. Guarda tu historial si lo deseas (opcional según implementación).
